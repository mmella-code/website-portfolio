# My Personal Portfolio Website

## About the Project

This is my personal developer portfolio website, created to showcase my skills, projects, and journey as a web developer.

The portfolio provides an overview of who I am, the technologies I work with, and some of the projects I have built while learning and improving my web development skills.

## Features

- **Home:** Introduction and welcome section.
- **About:** A brief description of myself and my interests in technology.
- **Projects:** Showcases my web development projects.
- **Contact:** Provides a way to get in touch with me.

## Projects Featured

Some of the projects showcased in my portfolio include:

- **Calculator:** A simple calculator application.
- **Digital Clock:** A clock that displays real-time updates.
- **Temperature Converter:** An application for converting temperatures.

## Technologies Used

- HTML5
- CSS3
- JavaScript
